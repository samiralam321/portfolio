# ⚡ Samir Alam - Personal Portfolio

A sleek, minimal, and responsive single-page personal portfolio built with **React 19**, **Vite**, **Tailwind CSS v4**, and **Framer Motion**. Features a macOS-inspired interactive spring dock and horizontal project carousel.

🌐 **Live Demo:** [samirin.vercel.app](https://samirintech.vercel.app/)

---

## ✨ Features

- 🎨 **Minimal & Modern UI:** Clean, distraction-free aesthetic with smooth theme transitions.
- 🚀 **Interactive Dock:** macOS-style magnifying spring dock for main navigation and social profiles.
- 📱 **Project Carousel:** Interactive horizontal card slider with smooth arrow navigation.
- 📬 **Direct Contact Form:** Serverless background email integration via FormSubmit.co.
- ⚡ **Blazing Fast:** Built on Vite 6 & React 19 for maximum performance.

---

## 🛠️ Tech Stack

- **Frontend:** React 19, Vite
- **Styling:** Tailwind CSS (v4)
- **Animations:** Framer Motion
- **Icons:** Lucide React & Custom SVGs
- **Deployment:** Vercel

## 🚀 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/samiralam321/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
